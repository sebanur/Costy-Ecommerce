<h1>COSTY–Ecommerce</h1>

<p>A responsive e-commerce website developed with <strong>HTML5, CSS3, and JavaScript.</strong></p>

<h2>Features</h2>

<ul>
  <li>Dynamic product listing with API</li>
  <li>Add to cart functionality</li>
  <li>Cart quantity and total price calculation</li>
  <li>Local Storage for cart data</li>
  <li>Responsive navigation</li>
  <li>Modular JavaScript structure</li>
</ul>

<h2>Technologies</h2>

<p><strong>HTML5 · CSS3 · JavaScript · Fetch API · Local Storage · Bootstrap Icons</strong></p>
